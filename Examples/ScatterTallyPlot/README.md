I love working with scatter plots.  The ability to visualize lots of data points all within the same view can be helpful with discovering clusters, seeing patterns and even identifying outliers.  However, when the scatter plot’s points are really bunched together it can be difficult to determine their relative locations on the X and Y axis.  After thinking it over, I realized that to solve this problem, two additional tally graphs could be added to a standard scatter plot on both the x and y axis.  Which is easy to do in [SAS® Visual Analytics](https://go.documentation.sas.com/doc/en/vacdc/default/vawlcm/home.htm) using the [SAS® Graph Builder](https://go.documentation.sas.com/?cdcId=vacdc&cdcVersion=default&docsetId=grbldrug&docsetTarget=titlepage.htm&locale=en)!

I began by opening the [SAS® Graph Builder](https://go.documentation.sas.com/?cdcId=vacdc&cdcVersion=default&docsetId=grbldrug&docsetTarget=titlepage.htm&locale=en) and in just a few minutes, I was able to create the graph below.  First, I took a standard scatter plot, and then I added two vector plots in new cells along the outer x and y axes.  After that, it was just a simple case of sharing some roles and updating the legends!

For this report's data source, the "cars" dataset available in the "SASHELP" library is used.
